Zoom the plays track on phones, add a scrollbar

Zoom level: one decision

A · Fixed 300% on mobile Recommended

  • One constant in AnnotateTimeline; desktop untouched.
  • Matches laptop density: 360 px phone track becomes ~840 px of content.
  • No zoom controls, no badge, nothing to persist.
  • Landscape phones get ~2100 px of content; if that feels like too much, scale from the measured track width instead (same code path, one expression).

B · Pinch to zoom, 100 to 500%

  • Adds a two-finger gesture handler on the track plus a zoom indicator.
  • Conflicts with browser page zoom; the plays layer already has to fight that (RegionLayer.jsx:117).
  • Needs a reset affordance and a story for where the window lands after a zoom.
  • Can layer on top of A later if users ask for it.
