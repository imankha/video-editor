Epic 1/6 of [On Fire](EPIC.md). See EPIC.md for the algorithm evaluation and design constraints (sprite-based render, preview == export, original art only).

## Problem

Every overlay effect has to exist three times (SVG preview, backend numpy, Modal inline numpy that cannot import `app`). T5250 skipped glow/pulse because a time-varying effect was hard to mirror. The fire needs a foundation that makes mirroring trivial: byte-identical assets plus a pure placement function with a parity test, before any render code is written.

## Solution

1. **Original flame art, generated offline.** A checked-in script (`scripts/generate_heat_sprites.py`, Pillow + numpy noise, deterministic seed) renders 24-frame RGBA loops at 256 px for: `plume`, `trail`, `ember`, `smoke`, `ring`, `burst`. Output committed under `src/frontend/public/heat/` (the preview loads them by URL) and read by the backend from the same directory at export time. No NBA Jam assets are copied; the script IS the art source so it can be re-tuned (open question 1 in EPIC.md).
2. **Placement spec, pure and mirrored.** `heat_placements(t, level, anchor, velocity, radius, region_start, region_end, reveal_factor) -> [placement]` where a placement is `{sprite, frame_index, cx, cy, scale, rotation_deg, alpha, blend}`. Rules: `frame_index = floor(t * 12) mod 24`; feet point `(x, y + radiusY)`; trail rotation `atan2(-vy, -vx)`; intensity `clamp(|v| / v_ref, 0.3, 1.0)` with `v_ref = 0.5 * frameHeight / s`; `heating` emits ember + ring tint only; `fire` emits plume + trail + ring + smoke; alpha multiplied by the T5250 reveal factor. Three copies: `src/frontend/src/utils/heatPlacements.js`, `src/backend/app/services/heat_placements.py`, inline `video_processing._heat_placements`.
3. **Velocity helper.** `spline_velocity(keyframes, t, dt)` = central finite difference of the existing Catmull-Rom position, added next to each spline copy (frontend `interpolateHighlightSpline`, backend `keyframe_interpolator.interpolate_highlight`, Modal `_spline_interpolate_highlight`).
4. **Parity test.** `tests/test_heat_placements.py::TestModalInlineParity` runs the backend and Modal-inline copies over a grid of `(t, level, velocity)` and asserts identical output; a Vitest fixture file (JSON generated by the Python test) pins the JS copy to the same numbers.

### Technical Notes
- Sprite sheets are small (24 x 6 x ~30 KB = ~4 MB total); they are shipped to Modal as bytes per call in T9230, so no image rebuild is needed to change art.
- Keep the spec numerically boring: integers for frame index, radians only inside `atan2`, no randomness. Randomness is what breaks parity.
- `blend` is `screen` for plume/trail/ember/ring/burst and `normal` for smoke.
