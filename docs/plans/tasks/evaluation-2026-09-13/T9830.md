## Outcome record

- **Root cause / finding.** The literal helper-text bug the brief opened with (four-star "one more
  star creates a clip") was a COPY defect already fixed by T9820. The still-live defect was a
  rating-driven DEFAULT in `AnnotateFullscreenOverlay.jsx`: `createProject` seeded from
  `rating===5 && myAthlete`, re-flipped at three auto-flip sites unless `createProjectManuallySet`,
  a create-mode "Clip" toggle, and a Save button whose LABEL switched SAVE_PLAY / SAVE_PLAY_AND_CLIP —
  i.e. the "dynamically switching primary action" the brief said to stop doing. Backend
  (`clips.py`) never gated on rating and is idempotent by natural key; only stale docstrings were wrong.

- **Change (behavior only; no new copy — T9860 owns vocabulary).** Replaced the toggle +
  label-switching Save with TWO always-visible, always-enabled outcomes in every layout —
  "Create an editable clip" (`ANNOTATE.CREATE_EDITABLE_CLIP`, createProject true) and "Save play"
  (`ANNOTATE.SAVE_PLAY`, createProject false). Deleted the three auto-flip sites +
  `createProjectManuallySet`. Moved rating + the sport prompt into the existing `detailsOpen`
  disclosure via a new shared `DetailsFields.jsx` (desktop strip panel, desktop formBody
  expand-in-place panel, mobile `AddDetailsPopup`). De-ambered `NoSportTagWarning` (shared, 4 sites).
  Added an in-flight save guard (`saveInFlightRef`) in `handleSave`. Fixed stale "5-star
  auto-creates a project" docstrings.

- **Changed paths.** `src/frontend/src/modes/annotate/components/AnnotateFullscreenOverlay.jsx`,
  `.../DetailsFields.jsx` (new), `.../AddDetailsPopup.jsx`,
  `src/frontend/src/components/shared/StarRating.jsx` (opt-in `showLabel`),
  `src/frontend/src/components/shared/NoSportTagWarning.jsx`,
  `src/frontend/src/hooks/useRawClipSave.js` (docstrings),
  `src/backend/app/routers/clips.py` (docstrings). Tests: new
  `AnnotateFullscreenOverlay.explicitOutcomes.test.jsx` (8) + updated
  layer/stripLayout/oneTap/keys/saveStatus/focusPrompt/mobileStageCta.

- **Acceptance-criteria mapping (T07.md).**
  - AC1 "unrated / four-star / five-star use the same obvious creation action" →
    `explicitOutcomes` AC1 + `layer.test` "two explicit Save outcomes, independent of rating/layer"
    + `stripLayout` "5-star … SAME two buttons".
  - AC2 "Save play only creates no draft/render, spends no credits" → `explicitOutcomes` AC2
    (createProject false; creating a project never spends credits — only a render does).
  - AC3 "Create highlight is idempotent and needs no reel or optional metadata" → `explicitOutcomes`
    AC3 (empty form: tags [], notes '', no sport) + AC4 double-click one-create (idempotency).
  - AC4 "later creation from an existing play preserves its source interval and name" →
    `ClipDetailsEditor.reel.test.jsx` (unchanged NO_PROJECT path fires a surgical
    `onUpdate({createProject:true})` — no interval/name in the payload, so both are preserved).
  - Validation "cancel, double click, failed-save retry; both outcomes at narrow/fullscreen" →
    in-flight guard tests + `explicitOutcomes` "both outcomes on every layout" (strip / mobile
    inline / landscape) + existing saveStatus error-path tests (Cancel unchanged, side-effect free).

- **Deviations.** (1) `landscape-inline` keeps the rating INLINE rather than behind a disclosure —
  that layout never had the T8600 disclosure and is the most height-starved surface (T8600 itself
  deferred it); its two outcome buttons ARE present. (2) `getRatingCaption` (clipConstants.js) is now
  dead in production (all 3 overlay call sites removed) but left intact + unit-tested — it is
  T9820's function and its tests must keep passing; the two buttons carry the outcome, so no
  create-mode caption. (3) The `overlay` (default) layout is not a production render site (only
  strip/inline/landscape-inline are) but is kept coherent since the test suite exercises it.

  shared + AnnotateModeView + AnnotateContainer). No live-drive/screenshots: this container has no
  browser/backend (same limitation recorded for T9630/T9820); coverage spans desktop-strip,
  mobile-inline and landscape layouts.
