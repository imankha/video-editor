## Outcome record

- Status and verified remaining scope: fixed and merged to master (STAGING); this was NOT a
  "reproduce or close" outcome — a dedicated expert (Opus) root-cause investigation confirmed two
  real, distinct defects, neither covered by T9470 (a different component, `DraftReelPreview.jsx`,
  unrelated to this flow — the PLAN.md gate note was a shallow pattern-match, not actual coverage).
- Root cause or capability: (1) the live Focus-completion path never called
  `POST /api/exports/acknowledge` at all — only the recovery path (View/Dismiss on the passive
  card) did — so every live completion stayed "recoverable" server-side for up to 24h regardless
  of whether the user had already acted; (2) T9285's Option C auto-navigate (merged 2026-09-12,
  the day before this evaluation) used a non-persisted one-shot guard that reset on every full
  reload, and had no signal distinguishing "the app's own redirect put the user here" from "the
  user genuinely cold-reloaded on their library" — combined with (1), a reload would find the
  still-unacknowledged job and auto-navigate into the old Focus completion screen (E32->E33).
- **User decision (2026-09-14, asked explicitly since it reverses part of an approved, one-day-old
  feature): Option C's auto-navigate removed entirely**, keeping only the passive dismissable card.
- Changed implementation paths / commit: `src/frontend/src/components/FocusCompletionRecovery.jsx`,
  `src/frontend/src/containers/ExportButtonContainer.jsx` (threaded the export job id — already
  identical to the backend's `export_jobs` primary key — through all 4 `onProceedToOverlay` call
  sites), `src/frontend/src/screens/FocusScreen.jsx` (job id carried on the preview payload,
  acknowledge fired from all 4 post-preview gesture handlers), `src/frontend/src/screens/
  focusCompletionOffer.js`, `src/frontend/src/stores/focusCompletionStore.js` (removed the dead
  `autoTriedJobId` one-shot state), `src/frontend/src/utils/resumeFocusCompletion.js`, new
  `src/frontend/src/utils/acknowledgeExportJob.js` (extracted shared helper, both the recovery and
  live paths now use the identical implementation) + updated `e2e/T9285-recovery-preview.qa.spec.js`
  and `.claude/knowledge/export-pipeline.md`. Merged via PR #429, commit `beb45cc7` on
  `feature/T9790-stop-reload-hijack` (merge commit `90953e2e`).
- Tests and screenshot/media evidence: 65 targeted unit tests + 118 vitest-related for changed
  sources + 4/4 e2e against real servers, all green. Supervisor-produced red/green proof for BOTH
  defects: reverted the 6 changed source files to pre-fix (keeping the new tests and the new
  `acknowledgeExportJob.js` util) and reran the 4 relevant test files -> 13 failed (10 for the
