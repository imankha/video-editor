## Outcome record

**Status and verified remaining scope:** implemented on `feature/T9870-autosave-and-result-retention`
(M-tier, frontend-only, no schema, no backend surface). This was a **reconciliation** task: an audit
(code-expert + session) found 3 of 4 acceptance criteria and 3 of 4 "work to perform" items already
satisfied by the existing architecture + merged deps (T9770/T9780/T9790/T9830/T9860). The genuine
remaining scope was **AC1 honesty** only. No remaining scope for this task; downstream flags below.

**Root cause / capability finding:**
- **Autosave (#1) already exists** — in-progress crop/spotlight/trim edits persist surgically PER
  GESTURE via `api/actionClient.js` (per-entity FIFO, `expected_version` threading, 409→reload,
  optimistic apply + rollback, `onError` toast). Ordered, acknowledged, retryable, old-draft
  compatible. No debounce exists or is wanted; adding a second writer would violate the single-
  write-path rule.
- **Retention (#2) already durable** — the backend export finalizer (`upsert_working_video` /
  `export_final`, durable_sync) persists the working/final video AT export completion, independent
  of any frontend click. The post-export **"Save draft" ghost button persists NOTHING** — it is
  navigation-only (`FocusScreen.handleAddSpotlightLater`, `OverlayScreen.handlePublishLater`). The
  defect (E30/E31): its caption ("Keep it in your drafts and finish it whenever you want") falsely
  framed durability as gated on the click — the "redundant Save-draft step" AC1 targets.
- **Stable home (#3) already exists** — `openFinishedReel`→`DraftReelPreview` (private player,
  streams `final_video_id`); `draftStage.getDraftStatus` Draft/Private/Published axis.
- **No publish side-effect (#4) already holds** — publish is a separate explicit gesture; autosave/
  `/actions` never touch publish state.

**Change (the AC1 fix):** a retention reassurance line (`retentionNote` prop) above BOTH completion
action grids, derived once by the new **pure read** `utils/resultRetentionNote.js`
(`getDraftStatus` → `RESULT_RETENTION.{PRIVATE_DRAFT|PRIVATE_READY|PUBLISHED}`), plus reframed
`SAVE_DRAFT_CAPTION`s. The AC4 guard lives in the deriver: an already-published reel gets the
PUBLISHED line ("already published, its link is unchanged"), never "only you can see it", never an
implied visibility change. The explicit Save-draft control and the T9830 outcome buttons are
preserved.
