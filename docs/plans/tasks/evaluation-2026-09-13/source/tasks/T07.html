B03 · R2 · N02–N03 · S02

Observed

At four stars, the toggle allowed clip creation while the helper still said one more star creates a clip. The evaluator raised the rating unnecessarily; five stars was not a real requirement.

Suspected / investigation

Rating-driven defaults and separately maintained helper text may have drifted. Inspect all rating/creation combinations; do not infer backend gating from misleading copy.

Selected decision and work

Prefer two visible outcomes over a hidden toggle or unconditional clip creation. Do not dynamically switch primary action from previous stars/clicks.

  • Keep trim start/end, duration and optional name visible.
  • Put rating, sport, tags and notes under Optional details; remove warning styling for optional sport.
  • Create highlight saves one mark/draft and displays a persistent onward choice. Save play only returns to game marking position.
  • Make saves retry-safe and Cancel side-effect free; keep later creation available from a saved play.

Proposed replacement copy

  • Create highlight
  • Save play only
  • Name (optional)
  • Optional details: rating, sport, tags and notes
  • Create an editable highlight from this moment. You can keep marking plays afterward.

Bracketed values are dynamic data or explicit dependencies. Do not ship conditional claims before verifying them.

Acceptance criteria

  • Unrated, four-star and five-star moments use the same obvious creation action.
  • Save play only creates no draft/render and spends no export credits.
  • Create highlight is idempotent and does not require a reel or optional metadata.
  • Later creation from an existing play preserves its source interval and name.

Practical validation

  • Test outcomes × ratings plus cancel, double click and failed-save retry.
  • Check both outcomes at narrow/fullscreen layouts.
  • Parent test: make one highlight, then save three plays without creating highlights; record accidental drafts.
