## Selected implementation decision

Prefer autosaved edits and automatically retained successful private exports. Explicit Save remains fallback until durable confirmation/recovery are proven; never remove the only reliable save control prematurely.

## Work to perform

- Add ordered autosave with acknowledgement/error/retry and safe old-draft compatibility.
- Retain successful exports privately at completion; remove redundant Save draft only after verified retention.

- Expose watch/edit/back-to-library/keep-marking actions; never change publication visibility as a save side effect.

## Acceptance criteria

- [ ] Completion is durably retrievable without a redundant Save draft step.
- [ ] Rapid edits/reload/save retries preserve latest accepted state or clearly show an actionable failure.
- [ ] Watch loads eligible latest export; newer unexported changes never masquerade as finished media.
- [ ] Autosave and export retention never publish or modify an already shared version.
