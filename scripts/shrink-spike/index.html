Shrink spike: WebCodecs benchmark (T8830 single-shot + T8832 streaming)

Throwaway benchmark, not shipped to users. Pick a camera file (or a control clip), choose a mode, and press Run. single-shot reads the whole file into memory (T8830, fails past ~300 MB in Chrome). streaming feeds mp4box fixed-size chunks from a faststart-ordered view (T8832) - the mode meant for the real 3-17 GB files. See README.md for how to serve this page and where to point it.
